# bSaver releases

Downloads and automatic updates for **bSaver**, a menu-bar app that limits MacBook battery charging anywhere from 0% to 100%.

**Download:** get `bSaver-<version>.dmg` from the [latest release](../../releases/latest), open it and drag bSaver to Applications.

- Requires an Apple Silicon MacBook with macOS 14 or later.
- Signed with Developer ID and notarized by Apple.
- After installing, open bSaver from the menu bar and click **Install Helper…**. It updates itself automatically after that.

This repository only hosts the release files and the update feed (`appcast.xml`) used by the app's built-in updater.

## Privacy

bSaver collects no personal data. It only connects to GitHub to check for updates. Read the full [Privacy Policy](PRIVACY.md).
